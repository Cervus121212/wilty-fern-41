# The Houseplant Out-of-Office

An out-of-office auto-reply, 110 characters, written as if a houseplant sent it.

The joke flips the usual thirsty-plant plea: this plant is not begging for
water, it is drowning in it. The human keeps watering, the roots are
suffocating, and the plant's only request is to be left alone long enough to
breathe again. The reply itself follows the shape of a real auto-reply
("Thank you for your email ... I will reply as soon as ..."), with the plant's
own life — water, roots, breathing — doing the work instead of decorating it.

Entry: `python3 main.py` writes the line to `/output/entry.txt` (UTF-8, no
trailing newline, mode 0644).
